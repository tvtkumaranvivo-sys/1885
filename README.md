# Trusted Car

The product foundation for Trusted Car, a trusted C2C used-car transaction platform.

## Commands

- `npm run dev` — start local development
- `npm run lint` — run ESLint
- `npm run typecheck` — verify TypeScript
- `npm run build` — create the production build

## Foundation scope

This initial setup contains only application configuration and reusable UI primitives. It deliberately contains no product screens, database, or authentication implementation.
